# Neon Mouse Art Game (SHRINK Project)

An interactive lightweight mini-project built for the Hack Club SHRINK challenge, kept completely under 3kb.

## 🚀 What is this?
A single-file HTML app where moving your mouse across the canvas creates vibrant, randomized neon particle trails with glowing dynamic effects.

## 🛠️ How it was made
- **Single File:** Combines HTML5, CSS3, and JavaScript (`index.html`) into one compact bundle.
- **Canvas API:** Uses 2D context rendering and dynamic particle arrays to handle smooth physics and glowing animations.
- **Optimized & Minified:** Engineered to fit within the strict <3kb limit requirements.
